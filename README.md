# Muhammad Elshan — Portfolio

Cyberpunk personal portfolio built with **Next.js (App Router)**, **Tailwind CSS**, **Framer Motion**, and **Three.js**.

## Stack

- Next.js 16 + React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion (micro-interactions, tilt cards, scroll timeline)
- Canvas particle network + Three.js neon torus knot
- Lucide icons

## Sections

1. **Hero** — cursor spotlight, typing terminal, 3D neon scene  
2. **About** — expertise pillars  
3. **Projects** — filterable 3D-tilt cards with detail popups  
4. **Skills** — floating node graph + proficiency bars  
5. **Experience** — scroll-driven timeline  
6. **Contact** — form, copy-email, social links  

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

Update contact/social links and project URLs in `src/data/portfolio.ts`.
